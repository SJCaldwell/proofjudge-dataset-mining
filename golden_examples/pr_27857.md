## Initial Proof (6 lines, using grind)

```lean
theorem rpow_eq_top_of_nonneg (x : ENNReal) {y : R} (hy0 : 0 <= y) : x ^ y = top -> x = top := by
  rw [ENNReal.rpow_eq_top_iff]
  rintro (h|h)
  . exfalso
    rw [lt_iff_not_ge] at h
    exact h.right hy0
  . exact h.left
```

Note: The initial commit actually replaced this with `grind [ENNReal.rpow_eq_top_iff]` (one-liner), but this was rejected.

## Accepted Final Proof (1 line, using simp)

```lean
theorem rpow_eq_top_of_nonneg (x : ENNReal) {y : R} (hy0 : 0 <= y) : x ^ y = top -> x = top := by
  simp +contextual [ENNReal.rpow_eq_top_iff, hy0.not_gt]
```
